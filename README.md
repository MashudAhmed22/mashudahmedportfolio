## 🚀 Getting Started

### Clone the repository

```bash
git clone <repository-url>
```

### Navigate to the project

```bash
cd mashudahmedportfolio
```

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
